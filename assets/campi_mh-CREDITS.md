# Câmpi body asset provenance

`campi_mh.json` and `campi_mh.bin` contain the fitted body used from v36.

- Body geometry: MakeHuman hm08 base mesh and macro targets from [MakeHuman Community](https://github.com/makehumancommunity/makehuman). Core assets are [CC0](https://static.makehumancommunity.org/about/license.html).
- The project pipeline morphs the body, fits the existing Xbot skeleton and transfers skin weights; see `tools/mh_body.py` and `tools/mh_fit.html`. Clothing colours and boundaries are generated by the game.
- The existing Xbot skeleton/animations are Mixamo assets, subject to [Adobe's terms](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html), not CC0. This document does not relicense those components.
- The separate face retains the provenance and noncommercial BFM 2009 limitation described in the project README. The whole character/game must not be represented as entirely CC0.

Reproducibility limitation: the current body generation tools expect intermediate inputs under `/tmp/mh/`; those inputs and an export runner mentioned as `mh_fit.mjs` are not included. The shipped runtime body is self-contained.
